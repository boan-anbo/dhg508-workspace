# Every project requires a full end-to-end upgrade with zero half-baked placeholders.

<div class="body">
<div class="frame"><span class="label">Engine or Web — both are welcome</span><div class="text">

- **Real game engine (`Unity` / `Godot`)**: complete lighting, collision, audio/UI feedback, and WebGL/build export
- **Pure Web / HTML**: completely fine **if crafted thoroughly**—clean typography, responsive layout, zero dead buttons or raw JSON dumps

</div></div>
<div class="frame hot"><span class="label">Zero half-finished scaffolding</span><div class="text">

- no *"TODO"*, broken links, placeholder boxes, or unverified AI hallucinations
- every claim, character card, or database entry tied to real sources (`据 / 推断 / 设`)
- build something with **genuine historical and scholarly value** that you are proud to share publicly

</div></div>
</div>
